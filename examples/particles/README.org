#+title: Particle Toy
#+author: Larry Staton

* Particle Toy

A stub, deliberately — registered and openable from the hub, with the design
parked here until we build it.

** The plan

Recon on upstream ([[https://github.com/burinc/glitter-uikit/blob/main/src/glitter_uikit/widget.clj][=glitter-uikit.widget=]]'s =canvas-spec=; see also Apple's
[[https://developer.apple.com/documentation/quartzcore/calayer][CALayer]] docs and upstream's [[https://github.com/burinc/glitter-uikit/blob/main/examples/glitter_uikit/circles.clj][circles example]] — 7GUIs' [[https://eugenkiss.github.io/7guis/tasks/#circle][Circle Drawer]], the
=:canvas= widget's original client) settled the approach before any code:

- =:canvas= is an =NSButton= hosting *CALayer* circles driven by a =:circles=
  data prop. Layers is a =CALayer= that takes no
  part in hit-testing, so clicks always land on the canvas — sub-views would
  swallow them.
- Animation: =w/every!= wraps =NSTimer= scheduled on the main run loop, so the
  tick can =swap!= particle positions directly and the reconciler syncs the
  layers. Physics is pure Clojure over =[{:x :y :vx :vy} ...]= — spec it,
  like everything else.
- Timer lifecycle is the real design work: start on first open, and stop
  (=w/cancel-every!=) when the window closes — needs window-close awareness
  the shell doesn't have yet (an =NSWindowDelegate= =windowWillClose:=, or
  polling =isVisible= from the tick).
- If layer diffing chokes at particle counts worth having,
  =w/register-widget!= is public — a custom particle widget is the escape
  hatch. And an immediate-mode rlgl/raylib canvas
  ([[https://jlt-commons.github.io/raylib-jlt/][raylib-jlt]]) is the escape hatch beyond that — though raylib owns its own
  event loop, so it likely wants its own window/process rather than living
  inside the NSApp run loop.

** The build

How the plan survived contact:

- *The =:circles= prop held up.* Each circle is ={:x :y :r :selected?}= in
  canvas coordinates, rendered as CALayers (=sync-circles!= is a /wholesale
  rebuild/ per render — upstream's comment says "if this ever holds hundreds,
  revisit", so the particle count is capped at 60 and the tick runs at 25fps).
  =:selected?= gets repurposed as a brightness flag: burst particles render
  in the highlighted style.
- *Timer lifecycle went the polling route.* The plan's two options were an
  =NSWindowDelegate= =windowWillClose:= (a runtime-built class — more
  machinery) or checking visibility from the tick. The tick is already
  running, so it polls: each frame asks the window =isVisible= and cancels
  itself (=w/cancel-every!=) when the answer is no. To make that possible the
  registry's =:on-open= hook grew a /window-pointer argument/ — the shell
  hands each example its window, and this example is why. Reopening the
  window restarts the timer through the same hook. One FFI wrinkle: =BOOL=
  returns cross jolt's FFI as a Scheme /character/ (the same fact that bit
  glitter-uikit's =applicationShouldTerminate...= callback — its issue #1),
  so the check compares against =(char 0)=.
- *Physics is pure data.* ={:x :y :vx :vy :r}= vectors, gravity, and wall
  bounces with damping. The first launch measured the coordinate system the
  hard way: gravity was written for AppKit's unflipped bottom-left origin,
  and /the particles fell up/ — the canvas's layer tree uses top-left,
  y-grows-downward geometry, so gravity increases y. The step
  function is a pure fn from particle to particle; the timer's only job is
  =(swap! state update :particles step-all)= and the reconciler does the
  rest. Sixty reconciles a second of a 60-layer canvas is exactly the
  workload the wholesale-rebuild comment warns about, which is why both
  numbers are capped where they are.
- *Clicks burst.* The canvas click event carries ={:x :y}= in canvas
  coordinates (via =reg/event-value=); a click spawns eight bright particles
  at the pointer, capped by dropping the oldest.

#+begin_src clojure :tangle ../../src/demo/examples/particles.clj :mkdirp true :comments link
(ns demo.examples.particles
  (:require [clojure.spec.alpha :as s]
            [demo.registry :as reg]
            [glitter-uikit.ffi :as u]
            [glitter-uikit.widget :as w]))

(def ^:private W 360.0)   ; canvas size, fixed — physics and view share it
(def ^:private H 240.0)
(def ^:private GRAVITY 0.35)
(def ^:private DAMPING 0.82)
(def ^:private MAX-PARTICLES 60)

(defn- rand-particle [x y bright?]
  {:x x :y y
   :vx (- (* 6.0 (rand)) 3.0)
   ;; Negative vy = upward (y grows DOWNWARD in the canvas layer — measured,
   ;; see the step docstring). New particles fountain up, then gravity wins.
   :vy (- -2.0 (* 4.0 (rand)))
   :r  (+ 3.0 (* 4.0 (rand)))
   :bright? bright?})

(defn- seed-particles []
  (vec (repeatedly 24 #(rand-particle (* W (rand)) (* H (rand)) false))))

(defonce state (atom {:particles (seed-particles)}))

;; --- physics: pure data in, pure data out ------------------------------------

(defn- step
  "One tick of one particle. Gravity INCREASES y: the canvas layer's origin
  is top-left, y growing downward. (First shipped with the opposite sign on
  the assumption that an unflipped AppKit view's bottom-left origin applied
  — the particles fell UP. The layer tree behind the canvas uses flipped,
  top-left geometry; one measured launch beat the docs.) Walls bounce with
  damping."
  [{:keys [x y vx vy r] :as p}]
  (let [vy (+ vy GRAVITY)
        x' (+ x vx)
        y' (+ y vy)
        [x' vx] (cond (< x' r)        [r (* (- vx) DAMPING)]
                      (> x' (- W r))  [(- W r) (* (- vx) DAMPING)]
                      :else           [x' vx])
        [y' vy] (cond (< y' r)        [r (* (- vy) DAMPING)]
                      (> y' (- H r))  [(- H r) (* (- vy) DAMPING)]
                      :else           [y' vy])]
    (assoc p :x x' :y y' :vx vx :vy vy)))

(defn- step-all [ps] (mapv step ps))

;; --- animation lifecycle -----------------------------------------------------

(defonce ^:private anim (atom {:timer nil :win nil}))

(defn- window-visible? [win]
  ;; BOOL returns cross the FFI as a Scheme character (see glitter-uikit's
  ;; issue #1) — compare against (char 0), not 0.
  (not= (char 0) (u/objc-msg-send-0char win (u/sel "isVisible"))))

(defn- tick! []
  (let [{:keys [timer win]} @anim]
    (if (and win (not (window-visible? win)))
      ;; Window closed: stop ticking. Reopening restarts via :on-open.
      (do (when timer (w/cancel-every! timer))
          (swap! anim assoc :timer nil))
      (swap! state update :particles step-all))))

(defn start!
  "The :on-open hook: remember the window (the tick polls its visibility)
  and start the timer unless one is already running."
  [win]
  (swap! anim assoc :win win)
  (when-not (:timer @anim)
    (swap! anim assoc :timer (w/every! 40 tick!))))

;; --- view --------------------------------------------------------------------

(defn view [{:keys [particles]}]
  [:vbox {:spacing 10 :margin 16}
   [:label {:markup [:span {:size "large" :weight "bold"} "Particle Toy"]}]
   [:label {:markup [:span {:size "small" :foreground "#8e939d"}
                     (str (count particles)
                          " particles · click the canvas to burst")]}]
   [:canvas {:width-request W :height-request H
             :circles (mapv (fn [{:keys [x y r bright?]}]
                              {:x x :y y :r r :selected? bright?})
                            particles)
             :on {:click [[:action.particles/burst]]}}]
   [:hbox {:spacing 8}
    [:button {:label "Seed" :on {:click [[:action.particles/seed]]}}]
    [:button {:label "Clear" :on {:click [[:action.particles/clear]]}}]]])

;; --- actions -----------------------------------------------------------------

(defmethod reg/action-spec :action.particles/burst [_]
  (s/cat :kind #{:action.particles/burst}))
(defmethod reg/action-spec :action.particles/seed [_]
  (s/cat :kind #{:action.particles/seed}))
(defmethod reg/action-spec :action.particles/clear [_]
  (s/cat :kind #{:action.particles/clear}))

(defmethod reg/run-action! :action.particles/burst [event _]
  (let [{:keys [x y]} (reg/event-value event)]
    (when (and x y)
      (swap! state update :particles
             (fn [ps]
               (->> (concat ps (repeatedly 8 #(rand-particle x y true)))
                    (take-last MAX-PARTICLES)
                    vec))))))

(defmethod reg/run-action! :action.particles/seed [_ _]
  (swap! state assoc :particles (seed-particles)))

(defmethod reg/run-action! :action.particles/clear [_ _]
  (swap! state assoc :particles []))

(reg/register-example!
 {:id :particles :title "Particle Toy" :view view :state state
  :width 400 :height 350 :on-open start!})
#+end_src
